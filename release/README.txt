MDPro 思维导图查看器 - 桌面版发布包
====================================

本目录包含两个交付物：

1. MDPro-portable.exe (67.8 MB) — 单文件可执行版
   ──────────────────────────────────────────────
   双击即可运行，无需安装。
   会自动在当前目录解压并启动 MDPro 思维导图查看器。
   首次运行会在同目录创建 MDPro 应用文件（约 260 MB）。

   特点：
   ✓ 单文件分发（仅 68 MB）
   ✓ 首次运行自动解压到当前目录
   ✓ 可放在 U 盘、移动硬盘中使用
   ✗ 需要至少 300 MB 磁盘空间

2. MDPro-win32-x64/ (259 MB) — 绿色版（已解压）
   ──────────────────────────────────────────────
   直接运行目录中的 electron.exe 即可启动。
   适合直接复制到任意位置使用。

构建说明
========
  npm run build        # 构建单文件版 (MDPro-portable.exe)
  npm run build:dir    # 仅构建绿色版目录

技术说明
========
- SFX 压缩：使用 7z LZMA2 算法（最大压缩比）
- 启动器：Electron 31.7.7 + 应用代码 asar 打包
- 文件大小：压缩前 259 MB → 压缩后 68 MB（压缩率 74%）
- 启动时间：首次解压约 3-5 秒

清理
====
  绿色版/解压文件可直接删除
  SFX 解压后不会自动清理（用户友好）
